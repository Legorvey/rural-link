Model Matematis & Persamaan Inti (src/)

          

          

            PL(f_GHz, d_m) [dB] = 32,4 + 20·log₁₀(f_GHz) + 10·n·log₁₀(d_m) + X_σ,   X_σ ~ N(0, σ²)

            Pr [dBm] = Pt + Gt + Gr − L_feeder − L_body − PL

            N [dBm] = −174 + 10·log₁₀(N_RB · 180.000 Hz) + NF,   SNR_dB = Pr − N

            Eb/N0 [dB] = SNR_dB − 10·log₁₀(k),   k = log₂(M),   Rb [bps] = N_RB · 180.000 · k

            C_Shannon [bps] = B_active · log₂(1 + SNR_linear)  (referensi teoretis saja)

    Batasan Model, Referensi, & Pekerjaan Lanjutan
    
          
    
          
      
            
    • Cakupan riset utama vs sensitivitas: Konfigurasi riset utama adalah 900 dan 1800 MHz pada target BER 10⁻². Opsi 700 MHz (terinspirasi Reddy 2022 di atas model CI Park 2023) dan BER 10⁻³ adalah suplemen eksploratori, bukan replikasi Reddy (2022).
      • 
            
    • Laju nominal tanpa coding: Laju Rb = B_active × log₂(M) bersifat tidak terkode (uncoded) tanpa FEC, pilot, cyclic prefix, atau penjadwalan MAC; nilai ini bukan throughput jaringan LTE aktual.
      • 
            
    • Ekstrapolasi model CI: Parameter Park dkk. (2023) diukur pada 1400 MHz di Korea Selatan dan diekstrapolasikan ke 900/1800 MHz; belum dikalibrasi dengan pengukuran lapangan wilayah 3T Indonesia.
      • 
            
    • Model yang sengaja tidak disertakan pada rilis ini (pekerjaan lanjutan): Fading Rician dan model difraksi medan tidak disertakan karena pendekatan pengali SNR dan difraksi tanpa profil elevasi medan (ITU-R P.526/P.1812) tidak valid secara ilmiah; keduanya dicatat sebagai pengembangan lanjutan.
      • 
            
    • Peta zona radial & sensor kanan: Peta radial merupakan model jarak hipotetis 1–12 km (bukan peta geografis). Radius yang mencapai ujung grid 12 km bersifat tersensor kanan (≥12 km).
      • 
            
    • Referensi utama: Reddy dkk. (2022) DOI 10.1186/s13638-022-02133-3; Khan dkk. (2025) DOI 10.1038/s41598-025-16743-6 (dengan koreksi faktor Gray BER); Park dkk. (2023) arXiv:2305.01152; Yogapratama (2015) Table IV; Cho & Yoon (2002); Laporan Kinerja Komdigi (2025).
      • 
            
    • Atribusi tim & desain antarmuka: Bahasa visual workbench terang, rail parameter, strip telemetri, grafik SNR, konstelasi, dan peta zona radial dibangun dari desain asli HTML/CSS/JS karya Zahran (diarsipkan di prototypes/dashboard_interaktif_siskom.html) yang diintegrasikan ke API Python tervalidasi (src/). Tim Kelompok 1: Aditya, Zahran, Baihaqy, Jeyd, Rizqul, Yusril.
